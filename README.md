# Ontario Family Law Agent

Content-first AI assistant repository for Ontario family law education and high-conflict co-parenting support.

## Canonical Docs
- Product overview: `docs/README.md`
- Product requirements: `docs/PRD.md`
- Agent system behavior (source of truth): `docs/CLAUDE.md`
- Architecture overview: `docs/architecture/overview.md`
- Legal boundary language: `docs/LEGAL_DISCLAIMER.md`

## Repository Structure
- `skills/`: task-specific agent skills
- `knowledge-base/`: legal and procedural reference material
- `templates/`: reusable drafting artifacts
- `response-frameworks/`: triage and conversation scaffolds
- `integrations/`: Supabase and CustodyBuddy integration artifacts
- `automation/`: workflow blueprints
- `testing/`: evaluation rubrics and scenarios
- `admin/`, `maintenance/`: governance and upkeep

## Quick Start
1. Read `QUICK_START.md`
2. Review `INDEX.md` for navigation
3. Start with a relevant skill in `skills/`

## Status
This repository is in a documentation/content buildout phase. Some files are intentionally placeholders and tracked in `docs/architecture/content-gaps.md`.
